## 💻 Featured Projects

### [MEWS: Measuring Equivalent Width in Spectra](https://github.com/InfinitelyCurious/Measuring-Equivalent-Width-in-Spectra-MEWS-)
Automated pipeline for accurate equivalent width measurements in galaxy spectra with built-in validation and adaptive continuum fitting. Validated against manual measurements for 183+ E+A galaxies.

**Tech:** Python, Astropy, Specutils, Matplotlib

### [MaNGA Color-Mass Analysis Tools](https://github.com/InfinitelyCurious/MaNGA-Color-Mass-Analysis)
Comprehensive color-mass analysis suite with empirically-derived green valley boundaries and dust corrections for SDSS-IV MaNGA galaxy samples.

**Tech:** Python, Astropy, Pandas, NumPy

### 183 E+A Galaxy Catalog *(Coming Soon)*
Complete catalog of spatially-resolved post-starburst galaxies with diagnostic measurements, morphologies, and WHAN/BPT classifications.
